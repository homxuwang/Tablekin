# 菜单与分类排序

用户已授权添加拖动排序和置顶功能。在现有厨房管理增加两个排序入口，分别进入共用排序页面。长按手柄拖动，边缘自动滚动；每项支持置顶、置底。顺序先在本地预览，保存后同步顾客菜单。取消不保存，操作中不允许重复提交。置顶是移动到列表第一位，不是永久置顶标记；分类排序不修改菜品分类，菜品使用厨房全局顺序，分类筛选保留相对次序。

## 实施步骤

1. 新增 utils/menu-sort.js：纯排序和拖动目标计算；写移动、越界、空列表测试。
2. API 新增 reorderKitchenItems，调用 reorder_kitchen_items 原子RPC；校验ID集合和kind，传原顺序用于冲突检测。
3. 新增 pages/sort 页面：先校验成员身份再加载完整列表，长按拖动、置顶/置底、保存、失败保留、刷新及取消、后台清理定时器。
4. manage 增加分类/菜品排序入口，app.json 注册页面；读排序沿用现有 sort_order,id。
5. WorkBuddy 文档说明原子RPC、权限、并发冲突及重试行为。
6. 跑相关测试和全量检查。云端部署与真机触摸交互需后续联调，不宣称已验证。
